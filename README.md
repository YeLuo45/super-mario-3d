# Super Mario 3D

经典2.5D侧视角马里奥游戏，使用 Three.js 开发的 HTML5 版本。

## 项目说明

本项目是一款使用纯 HTML5 + JavaScript 开发的 2.5D 平台跳跃游戏，基于 Three.js 的 3D 渲染引擎，采用侧视角正交相机呈现经典的马里奥游戏体验。

## 技术栈

- **渲染引擎**: Three.js r128 (CDN)
- **相机**: OrthographicCamera 正交相机（侧视角）
- **物理**: 自定义 AABB 碰撞检测
- **音频**: Web Audio API 程序化合成
- **重力**: 25 units/s²
- **时间步**: 固定 dt = 1/60

## 游戏操作

| 按键 | 功能 |
|------|------|
| ← / A | 向左移动 |
| → / D | 向右移动 |
| ↑ / W / Space | 跳跃 |

## 核心机制

- **移动**: 水平移动，支持方向切换
- **跳跃**: 固定跳跃力，支持蹬墙跳
- **踩敌人**: 跳到敌人头顶可消灭
- **金币**: 收集增加分数
- **管道**: 场景障碍物
- **终点**: 到达旗杆过关

## 敌人类型

- **Goomba (蘑菇怪)**: 棕色蘑菇敌人，巡逻移动，被踩消灭
- **Koopa (乌龟)**: 绿色乌龟敌人，第一次被踩缩壳，第二次消灭

## 运行方式

直接用浏览器打开 `index.html` 即可运行游戏。

## 开发说明

游戏采用固定时间步物理模拟（dt = 1/60），确保物理行为的一致性和可预测性。所有游戏逻辑在 `js/game.js` 的 `update()` 方法中按固定时间间隔执行，渲染则在 `requestAnimationFrame` 驱动的主循环中独立运行。
