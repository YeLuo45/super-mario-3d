# Super Mario 3D — 游戏概念设计文档

## 1. 游戏概念（1段）

**Super Mario 3D** 是一款基于 HTML5 Three.js 开发的 2.5D 侧视角平台跳跃游戏。玩家控制 Mario 在由 3D 几何体构建的世界中冒险，体验经典的红白机超级玛丽核心玩法——踩敌人、顶问号砖吃金币和蘑菇、蹬墙跳越过高墙、钻进管道穿梭关卡。游戏保留 2D 侧视角的操控直觉，同时以 3D 渲染赋予场景纵深感和立体光影。

## 2. 核心机制（不超过8条）

1. **移动与加速**: 左右方向键/AD 控制水平移动，按住加速键实现冲刺。
2. **跳跃**: 空格键跳跃，按住蓄力可跳更高。
3. **踩敌人**: 落在 Goomba、Koopa 等敌人头顶使其消灭或翻转。
4. **变强道具**: 金币吃满后额外生命+1。
5. **金币与计分**: 收集金币增加分数，终点旗杆触发表演分评判。
6. **管道穿梭**: 特定管道可钻入，瞬间传送至另一出口位置。
7. **关卡重力与碰撞**: 固定重力引擎，基于 AABB 碰撞检测。
8. **敌人 AI**: Goomba 直线巡逻、Koopa 在壳状态下可被踢出撞击。

## 3. 视觉风格

- **渲染风格**: Low-Poly 3D，几何体构建场景物体。
- **视角**: 固定侧视角，OrthographicCamera 侧视角相机。
- **配色**: 经典 NES 调色盘——天蓝色背景、亮绿色草地。
- **光照**: Lambert 漫反射 + 环境光，角色加微量边缘光。
- **特效**: 粒子爆发（金币飞散）、尘土粒子。
- **UI**: 屏幕上方显示金币计数、当前分数。

## 4. 音效建议

| 场景/动作 | 音效描述 |
|---|---|
| 背景音乐 | 8-bit 合成器主旋律 |
| 跳跃 | 短促上扬的"噗"音 |
| 踩敌人 | 低沉"砰"声 |
| 吃金币 | 清脆叮咚音 |
| 死亡 | 经典下降滑音 |
| 关卡通关 | 胜利号角 |

> 使用 Web Audio API 程序化合成 8-bit 风格音效。
